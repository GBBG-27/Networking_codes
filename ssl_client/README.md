## Description

This is a simple client side script the connects to a 

server.Data transmitted within the network is encrypted.

I used SSL (Secure Socket Layer) for the secure connection,the 

successor of TLS (Transport layer Security). Though the protocol I used

for security is outdated,I'm just demonstrating how it works.This client is 

similar to all the previous clients i have created,the difference is that data

being transmitted on the network is encrypted and secured.
