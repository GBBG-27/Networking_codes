## Description

This is a simple client that connects to a server,

sends data and print the received data out.When it 

starts,you will be prompt to enter a hostname,it could

be an IP address or a domain name,then a port number.When 

a connection is made,it will be printed out that " Connected ".

Next prompt will be two greater that signs which shows data is ready 

to be sent,type in your data and click enter,it will be sent and

if there is a responds,it will be printed out.After receiving the data 

you will still be prompt for more data to be sent.When the other side 

disconnects,you will be notified when you send data.

## Usage

##### - Make sure you have python installed on you computer[  It is pre-installed on some unix based computers  ]
##### - Get the script,then run it [ run ' python select_client.py' ]
##### - Enter the hostname,click Enter
##### - Enter the port number and click Enter 
##### - On the next prompt,type in the data to be sent,then click enter
##### - If the connection is closed on the other end,you will be notified when you send data
